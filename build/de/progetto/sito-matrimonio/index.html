Hochzeits-Web-App

Full-Stack-Webanwendungsentwicklung

Rolle: Webentwickler & Designer

Tech Stack

HTML5/CSS3 JavaScript Python3.13 Flask

Projektübersicht

Erstellung einer maßgeschneiderten Webanwendung im Auftrag für eine Hochzeit. Die Website umfasst zwei Sprachseiten (Italienisch und Französisch), um alle Gäste problemlos zu erreichen. Das Design spiegelt das Piraten-Motto der Hochzeit durch spezielle Schriftarten und Hintergrundgrafiken im CSS wider. Die Textinhalte werden aus lokalen .txt-Dateien des Projekts ausgelesen. Der Text wird mit einem dynamischen 'Schreib-Effekt' durch eine Piratenflagge dargestellt, die von einem JavaScript-Skript am Ende der HTML-Datei gesteuert wird.

Hauptfunktionen

  • Anpassungsfähiges Design für alle Endgeräte
  • Kontrastreicher Header im Vergleich zum Hauptbereich
