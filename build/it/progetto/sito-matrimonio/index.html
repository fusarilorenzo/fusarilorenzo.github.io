Sito Web per Matrimonio

Sviluppo Web App Full-Stack

Ruolo: Web Developer & Designer

Tech Stack

HTML5/CSS3 JavaScript Python3.13 Flask

Panoramica del Progetto

Realizzazione di una web app personalizzata su commissione per un matrimonio. Il sito include due pagine, una per la lingua italiana e una per la lingua francese, in maniera da ricoprire tutti gli invitati con meno fatica possibile. Il sito richiama il tema del matrimonio con i font e la grafica dello sfondo descritta nel CSS. Il testo viene estratto da dei file .txt presenti nei file locali del progetto. Le lettere vengono 'scritte' da una bandiera pirata generata e gestita da uno script JavaScript posto al termine del file HTML.

Funzionalità Principali

  • Design adattabile a tutti i dispositivi
  • Header in contrasto con il corpo del sito
