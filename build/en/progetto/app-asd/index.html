Mobile App for Local Sports Club

Mobile Development

Role: Sole / Full-Stack Developer

Tech Stack

Swift Kotlin Firebase REST API Google Apps Script

Project Overview

Development and release of a mobile app for a local amateur sports club, allowing athletes to track their current season results, register for competitions, and view team events. User data is managed via a personal identification code generated upon account creation. Google Apps Script with JavaScript was used to communicate with Google Sheets. The application was built natively: Swift with SwiftUI for iOS/iPadOS, and Kotlin with Jetpack Compose for Android.

Key Features

  • User authentication and athlete profile management
  • Push notifications for urgent announcements and competitions
  • Calendar integration for events and training sessions
  • Display of competitive season results
  • Online competition registration
