Project Overview

Creation of a custom web platform commissioned by a private client. The site consists of four pages (two in Italian and two in English) following a showcase website structure. Built on WordPress using custom code, combining HTML and CSS for styling and JavaScript to access WordPress's native media gallery. Images are categorized using community plugins to prevent asset conflicts across languages.

  • On-page SEO optimization for search engines
